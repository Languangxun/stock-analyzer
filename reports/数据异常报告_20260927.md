## 三、待决策：腾讯 hfq 是仿射变换，日收益率被逐股缩放（严重）

**结论**：库内主口径（热修⑩起统一为腾讯「后复权 hfq」）**不是乘法后复权**。
实测腾讯 `hfqday` 在不含除权的区间内严格满足

```
hfq(t) ≈ a × 不复权价(t) + b     （段内 a、b 恒定）
```

于是整段日收益率被缩放为 `s = a·P / (a·P + b) ≈ 中位(hfq日收益 / 不复权日收益)`；
该缩放随每次除权除息跳变，且**每一根 bar 都受影响**（不是只在除权日）。

**证据（近 120 根拟合，配对同一交易日）**：

| 代码 | 名称 | 拟合 R² | 收益缩放 s | 备注 |
|---|---|---|---|---|
| sh600000 | 浦发银行 | 0.96 | **0.63** | 日收益被缩小 37% |
| sh601318 | 中国平安 | 0.98 | 0.72 | |
| sh600519 | 贵州茅台 | 0.98 | 0.82 | |
| sz000725 | 京东方A | 0.9998 | 0.87 | |
| sz300750 | 宁德时代 | 0.99 | 0.95 | |
| sz000005 | ST星源 | 1.0000 | **1.75** | 日收益被放大 75% |
| sh600653 | 申华控股 | 1.0000 | **1.75** | |

单日对照（`sh600653` 2018-08-01，涨跌停 ±10% 的主板股）：
不复权 `1.98→2.18 = +10.10%`（涨停）；腾讯 qfq `+10.1%`（正确）；
腾讯 hfq `+16.35%`（失真）。`sh600595` 2014-07-22/23 两天连续涨停，
不复权 +10.10%/+10.07%，hfq 报 +15.24%/+14.52%。

**影响面（抽样 8 只，5 只 |s-1|>2%）**：失真既非个别股票也非小量级；
v6.1.5 起（热修⑩/全库迁移后的）回测、因子、形态匹配所用收益率均带逐股
缩放，且缩放系数随时间（除权）变化。热修⑩的"重叠日偏差 0.0000%"验证是
**循环验证**（库内与源同为腾讯 hfq），未检出该问题。

**可复现体检**（新增，只读）：
```bash
python3 data_clean.py --check-adj --sample 300      # 报告 reports/复权体检_*.md
# GUI：工具 → 数据工具 → 模式选「复权失真体检」
```

**处置（2026-09-27 已确认并实施，全链切换）**：

用新浪复权因子 `finance.sina.com.cn/realstock/company/<code>/hfq.js`
× 腾讯不复权日K 重建**真乘法后复权**，已落到全部数据路径：

| 路径 | 改动 |

**验证**：`sh600000 / sh600653 / sh600595` 重建后收益比中位 **1.0000**、
