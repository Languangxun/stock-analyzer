# stock-analyzer

基于**历史形态相似度匹配 + 多维融合 + Walk-Forward 自适应 ML + 量化回测**的 A 股短线统计研究工具。

> **个人研究项目，输出仅供历史统计参考，不构成投资建议。**
> 欢迎交流（联系方式见网站底部）。

## 冠军 Baseline（2026-09-13 定版）

**冠军配置**：激进档 + 弱市覆盖（上证 5 日日均收益 < -0.6% 时 ATR 止损 ×0.5 且弱市停开仓）。
即 `--tier 激进 --weak-tiers 激进 --weak-skip-entry` 的实际口径；全样本更优版本为不停开仓（见下）。

**成绩（vs 上证指数 sh000001）**

| 段 | 激进 + 弱市覆盖 | 上证 | 超额年化 |
|---|---|---|---|
| val OOS（2025-03-26 ~ 2026-09-11，含停开仓） | **+14.3% / -12.5%，Calmar 1.14，Sharpe 0.86** | +10.3% / -11.3%，0.91，0.77 | **+4.0pp** |

| 全样本 1000 日（含停开仓） | +12.8% / -28.0%，Calmar 0.46，Sharpe 0.76 | 同上 | +8.0pp |

> **约定：以后所有新实验都以「激进 + 弱市覆盖」（冠军）为 baseline**，必须报告超额年化与风险调整指标（Calmar/Sharpe/回撤），并注明段口径（val OOS / 全样本 1000 日）。
> 第二/三步基准已入库：深证成指 `sz399001`、创业板指 `sz399006`（各 1100 根），`--benchmark` 可直接切换。

**复现命令**


**结论**

1. 在激进档，**单改任一退出旋钮都跑不赢默认 Full**（hybrid、移动止盈参数、ATR、单独调 exit_p/min_hold/cooldown 全部变差）；默认 dist + Q10 棘轮 + Q75 目标已是该档局部最优。
2. 唯一显著提升来自 **收紧止损（`stop_q=25`）+ 抬高目标（`target_q=90`）**：年化 +13.6%→+25.4%，回撤 -52.7%→-44.8%；再叠加「关闭升档再入场」把回撤压到 **-28.3%（Calmar 0.79）**。
3. **但收益高度集中在后半段**（前半 -1% / 后半 +68%），存在 regime 依赖与「55 变体选 1」的选择偏差；前后半段更均衡的是 `+min_hold5`（+13%/+8%）与 `+exit_p0.55`（+9%/+18%）。
4. **参数不可跨档移植**：Q25+Q90 在平衡档 -5.6%、保守档 -21.2%；平衡档相对最优为 `Q25+Q90+无p_up+cooldown10`（+8.4%，前半 +9% / 后半 +10%，较均衡）。
5. 头部候选已加入 `_V4_VARIANTS`（`Exit: Q25+Q90*`），后续 `--v4` 报告会一并输出；**升为默认前需做滚动窗口/分年度复核**（见下）。

#### 滚动窗口 / 分年度复核（2026-09-13）

> 脚本：`backtest_exit_roll.py`（250 日滚动窗、步长 60，共 5 窗，约 40s）  
> 结果：`research/v4_exit_roll_激进.json` / `v4_exit_roll_平衡.json`

**激进档**

| 变体 | 年化中位 | 最差年化 | Calmar 中位 | 正收益窗 | 回撤中位 |
|---|---|---|---|---|---|
| **Full(默认)** | **+16.8%** | **-5.3%** | **+0.55** | **80%** | -30.3% |
| Q25+Q90 | +5.4% | -13.9% | +0.18 | 60% | -30.5% |
| Q25+Q90+无再入场 | +12.6% | -22.5% | +0.41 | 60% | -30.5% |
| Q25+Q90+min_hold5 | +10.2% | -29.3% | +0.37 | 60% | -29.7% |

- 分年度看，Full 的收益主要来自 2025（+46.1%），2026 段 -7.8%；Q25+Q90 的收益集中在 2026（+48.4%），2025 仅 +7.6% —— 两者均为**单年度驱动**，不是稳定超额。
- Walk-forward 选型（窗口内选最优 → 下一窗验证）样本外年化中位仅 **+3.5%**，低于固定默认的 **+26.3%**，且选中的变体在窗口间反复切换 → 事后最优不可复现。

**平衡档**：默认 Full 滚动年化中位 -7.7%（仅 20% 窗口正收益），Q25+Q90 系列更差；全期 +8.4% 的 `Q25+Q90+无p_up+cooldown10` 也主要由 2026 段贡献（2025 -5.4% / 2026 +22.7%）。

**复核结论**：**不支持将 Q25+Q90 系列升为默认**。默认 dist + Q10 + Q75 在滚动窗下最稳，保持现状；头部候选仅保留在 `_V4_VARIANTS` 作为监测项。激进档真正的短板是 2026 段回撤（-52.7%），下一步应针对「熊市/震荡段的止损收紧」设计条件化规则，而不是全时段替换退出参数。

## 核心结论


1. **信号 IC ≠ 组合收益**：LightGBM 样本外 IC 为正（+0.016），但 Full v4 早期平衡/保守显著为负（-18.1% / -30.3%）；决策层更新后（2026-09-13）转正为 +1.1% / **+12.4%**，激进 +13.6%。选股信号只是必要条件，退出结构、持仓周期、交易成本共同定价最终收益。
2. **组件与默认结构矛盾**：Adaptive / Logistic / LightGBM / Quantile 去掉后年化都变差，四个组件各自有正贡献；但去掉 **Q10 棘轮**后年化 -5.8%（旧口径下显著优于 Full -18.1%），说明当前 Full 的 Q10 棘轮叠加是负贡献，默认退出结构需要重调。
3. **v4 平衡仍未跑赢旧基线（回撤维度）**：v3.3 Baseline · 稳健 +1.5% / -17.5%，vs 更新后 Full v4 · 平衡 +1.1% / -47.2%，年化接近但回撤深一倍以上，决策层增量主要体现在删减规则而非超越旧基线。
4. **板块轮动仍是正向门槛，但最优参数变了**：所有轮动变体都优于无轮动基准，最佳为 **Rot-Top50（-6.7%）** 与 **RotT10+DispHi（-8.1%）**；旧结论「只认前 30% / T10only」在修复后样本外不复现。
5. **过拟合未解决**：LightGBM 训练段 IC 中位 **0.645** vs 样本外 **0.016**。
6. **成本敏感**：平均持仓 5 日、滑点 0.1%/边、无佣金的口径下，多数档位接近或低于成本线。

### 优化点

- **回测提速约 3×（647s → 212s）**：
  - `_precompute_atr` 改为 numpy 向量化，ATR 每股只算一次并传入 42 次 `_bt_events`（原每次调用重算）；
  - 新增 `_composite_precompute`，多维评分的 7 个指标/筹码分布每股只算一次，供 3 档风险复用；
  - 指数 regime 不再随每个任务 pickle，改为 worker 进程内缓存；
- **多进程并行**：`ProcessPoolExecutor`，默认 `min(8, CPU 核心数)`；
- **指数 regime 全市场共享**：上证指数 `sh000001` 只加载一次，所有股票共用；
- **单文件函数调用**：直接复用 `stock_gui.py` 的 `_sig_*` / `_composite_signals` / `_bt_events`，保证口径与 GUI 完全一致；
- **去除 GUI/tkinter 依赖**：纯 CLI，适合服务器后台跑批。

- 组合窗口为单一段落（2025-03~2026-09），且上述规则/参数均在该窗口上比较，存在元层面选择偏差。

### 进入/退出覆盖层寻优：弱市条件化（2026-09-13）

> 脚本：`backtest_portfolio_overlay_opt.py`；结果：`research/portfolio_overlay_opt.json`。
> 对象：每股选型不动（模型已拟合各自 train 段），只搜索组合层「弱市收紧止损 / 弱市停开仓」覆盖层。
> 协议：33 个预登记配置（ATR 缩放 0.4~0.8 × 弱市阈值 -0.4%~-1.0% × 是否停开仓）× 三档，
> 四口径评估（train / val / val 前半 h1 / val 后半 h2），三套选参口径（train→val、h1→h2、h2→h1 反向）+ 邻域平台检查。

**逐段精调参数均不可靠，但「弱市收紧」的方向在配置族上稳健（不是单点参数）**：

| 档位 | 覆盖层优于基线的配置占比（train/val/h1/h2） | 基线 | 配置中位数 | 结论 |
|---|---|---|---|---|
| 保守 | 67% / 33% / 27% / 33% | val +4.2% | val +2.5% | 无增益，维持基线 |
| 稳健 | 6% / 39% / 27% / **88%** | val -0.4%，h2 -11.4% | h2 -1.7% | 熊市段显著保护，但全样本 2023 转差（见下节）→ 不启用 |
| 激进 | 36% / **100%** / 48% / **70%** | val -6.0%，h2 -17.3% | val +7.5%，h2 -12.7% | 多数配置改善 val 与 h2，但 train 段仅 36%，依赖市场环境 |

- train→val 选出对稳健/激进为正（+3.0% / +11.3%），但平台检查多为孤峰；h1→h2 对保守/激进反而变差 → **按段精调具体参数不可信**。
- 为什么不扩大「每股进出参数」候选池：对 `strategy_ablation_per_stock.json` 21 个「算法×风险档」组合的验证段聚合显示，样本外年化中位全部在 **-0.1% ~ -4.1%**（仅 MACD 两档 ≈0），扩大候选只会加重选型过拟合，故优化改在组合层共享覆盖层。
- 因此不把单点参数写死进默认；提供按档启用经验证方向的开关（保守不启用）：
  `python backtest_strategy_portfolio.py --tier all --segment val --weak-tiers 激进`
  = 激进档启用 `ATR×0.5, mkt5<-0.6%`（val：-6.0%→+11.3%/-18.4%，`research/strategy_portfolio_slot_val_weaktiers.json`）。
- 覆盖层只收紧止损/停开仓，不改仓位大小。

**全样本复核（1000 交易日全 A，2022-07-25 ~ 2026-09-04，~5101 只活跃）**

> `--segment all --min-active 1000`（排除少数长停牌股撑出的稀疏早期日历）；注意全样本含每股选型的 train 段，数字偏乐观，样本外以 val 段为准。

## 荐股信号买卖回测（防前视 · 2026-09-13）

> 脚本：`backtest_picks.py`；结果：`research/picks_backtest_base500.json`；打分缓存：`research/picks_scores_500.pkl`（可用 `--scores-in` 秒级复跑参数）

**防前视设计**

1. 评估日 T 只用「截止 T 收盘」的数据打分（复用 `daily_pick_score`，其指标与筹码分布全部因果；行业 5 日收益也只累计到 T）；
2. T 日收盘后入围：非 ST/ETF/北交、`close≥2`、MA20/60 空头闸门不触发、`score ≥ buy_th`，按分数取 TopN；
3. **成交在 T+1 开盘**（涨停开盘弃买、跌停开盘顺延、停牌视为无开盘跳过），不使用 T 日收盘成交；
4. 成本：滑点 0.1%/边；期末按最后盯市价强平。

**基线（2024-08-21 ~ 2026-09-07，全市场 4956 只，评估步长 5 日）**

| 配置 | 年化 | 回撤 | Calmar | Sharpe | PF | 交易 |
|---|---|---|---|---|---|---|
| Top10 / 持仓≤10 / buy_th=2 / sell_th=0 / max_hold=20期 | **-23.9%** | -56.6% | -0.42 | -1.47 | 0.68 | 212 |

**参数扫描（14 组，全部为负）**：`sell_th` 0~3、`max_hold` 5~40、Top5~20、`buy_th` 2~4 组合下，年化区间 **-41.3% ~ -8.5%**；表现最好的 Top20/持仓20 仍为 **-8.5% / -35.9%**。

**入场闸门（大盘状态过滤，仍为负）**

| 过滤 | 年化 | 回撤 | Calmar | PF |
|---|---|---|---|---|
| 无（基线） | -23.9% | -56.6% | -0.42 | 0.68 |
| 仅大盘 > MA20 | -13.0% | -35.7% | -0.36 | 0.75 |
| 仅大盘 > MA60 | -18.9% | -45.1% | -0.42 | 0.61 |
| 仅多头排列（价 > MA20 > MA60） | -19.0% | -45.5% | -0.42 | 0.62 |

**分段**：前半段 -13.5%、后半段（2026）-27.3% —— 与全项目其他策略一致，2026 段系统性亏损。

**结论**：当前「多维荐股分」作为独立买入信号，在 2024-08 ~ 2026-09 全市场回测中**不盈利**，适合作为信息面板，不宜直接当交易信号。后续优化方向：改用样本外 IC 为正的因子（v4 LightGBM / L1 形态）做选股分，或叠加 ATR 止损与更严的大盘闸门后再评估。

## 数据与方法

### 数据

- 行情源：腾讯 → 东方财富（4 host 轮询）多源容灾；网易 163 / 新浪仅提供不复权价，已不再作为持久化源。
- 缓存：本地 SQLite `stock_cache.db`，WAL 模式，增量回填，负缓存 1 小时。
- 清洗：结构异常删除、整只重拉、退市登记、停牌报告、价格粘性检测。
  - 最近一次全库扫描（`python data_clean.py`，89 秒）：**5847 只 / 8,049,399 根**日K；结构异常 bar 172、越界疑似除权残留 1035、末价 <0.5 元 144、长停牌缺口 334、疑似退市 321、落后市场最新日 >10 天 398。
  - 修复（`python stock_predict.py --clean`）：删除结构异常 172 根、登记退市 321 只；重拉时增加「不得缩短历史（`len(new) >= min(len(old),400)`）」保护，避免上游截断把长历史覆盖成短历史。
- **复权口径（2026-09 修正）**：东财/腾讯的"前复权"用除权公式（现金分红做减法），长期高分红股历史价会趋近 0 甚至为负（如潞安环能 2020-02 收盘 0.088 元），造成全库 961 只 / 3791 处假跳变。现改为：
  - `daily_bars` 统一存**后复权 hfq**（乘法、恒正、收益率正确）；
  - `adjust(code, k)` 存显示缩放 `k=最新不复权价/后复权末价`，读取层（`get_daily`）按 `hfq*k` 还原"乘法前复权"给界面展示，收益率不变；
  - 回填/清洗 `_fetch_tencent`/`_fetch_eastmoney` 默认 `fq=hfq` / `fqt=2`，`backfill` 写入前做重叠一致性校验，基期不一致自动整只替换。
  - 全库迁移命令：`python data_clean.py --all-adj --workers 2`（断点续传，约 1~2 小时，同时补齐最近的缺失K线）。

### 因子（13 个，全部 T 日及以前）

`l1_up` / `l1_ret`（形态匹配上行概率/相似样本收益）、`bias20` / `bias60`（MA20/60 乖离）、`ret5` / `ret10` / `ret20`、`rsi14`、`atr_pct`、`vola20`、`volchg`（量变）、`mkt5`（大盘 5 日）、`ind5`（行业 5 日）。

### Walk-Forward 训练

- 扩展窗，折长 40 交易日，预热 60 日，首折训练 ≥180 日；
- 每折内完成：标准化、Lasso 筛选（α=0.005，全零则退回 IC×稳定性加权）、Horizon 内层选择（75/25 切分）、Logistic / LightGBM / Quantile Regression 拟合；
- 折间不重叠，严格无样本外数据泄露。

### LightGBM 超参（先验固定）

```python
num_leaves=15, max_depth=4, learning_rate=0.05, n_estimators=200,
min_child_samples=40, subsample=0.8, colsample_bytree=0.8, reg_lambda=1.0
```

### 组合回测口径

- 初始资金 100 万；
- 成本：滑点 0.1%/边，佣金/印花税 0；
- 成交：信号日收盘；涨停禁买、跌停顺延卖出、停牌持仓顺延、期末强平；
- 一手 100 股整数化。

4. 行业动量离散度 `disp_rank` 的三态路由（高分化 / 低分化 / 其他）待更多证据后定型。
