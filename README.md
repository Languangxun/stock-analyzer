# stock-analyzer · v6.4.0

A 股短线统计研究工具：**历史形态相似度匹配 + 多维融合 + 三档组合策略 + 全量回测**。
本地桌面 GUI 与命令行两种用法，计算全部在本地完成，AI 分析为可选增强。

> **免责声明**：所有输出仅为历史数据的统计推断与研究用途，**不构成任何投资建议**。
> 股市有风险，入市需谨慎。

## 功能亮点

- **三档组合策略（稳健 / 均衡 / 激进）——v6.2.3 定版，稳健档 v6.3.1 收紧**：信号只用 T-1 及以前数据、T 日收盘成交，
  含滑点/佣金/印花税/涨跌停/整手/停牌/退市的完整交易约束；**激进 = 板块轮动策略**——
  以板块轮动为进攻主线（强势行业选股 + 行业广度闸门、大盘权重降至 40% 让阀门开得更久），
  Top5/10 日切换、允许打板；**稳健档 v6.3.1 起 = IC 确认层 + Top10 + 换仓缓冲带10**
  （指标要求更严格：历史信号 IC 显著为正 + MA20/60 趋势在场；交易数约 -57%），详见「三档策略」；
  （档位沿革：原四档「稳健/均衡/激进/高风险」，v6.2.3 起原稳健策略淘汰、
  原均衡→稳健、原激进→均衡、原高风险→激进——策略本体逐字段未改，仅重定名）；
- **标准回测**：四口径（全A / 沪深主板 / ETF / 全A含ETF）× 三类产品（组合 / 荐股 /
  参数敏感性 / 分段），自动生成版本化产物、SVG 图表与本地网页仪表盘；
- **个股分析**：形态相似度匹配、买卖点风险偏好（保守/稳健/激进；v6.4.1 起可选
  `test`=sm701 模型直出、不消融）信号回放、筹码分布（同花顺口径）、
  MA/BOLL/MACD/KDJ/RSI/ADX、T+1/T+5 预测与幽灵K线；**策略消融优先读全市场批量结果**
  （v6.2.2：`tier_picks_from_ablation.py` 产出的三档缓存，弹窗秒开），读不到才本地重跑；
  分析报告显示 **`名称 (代码) [行业]` 与现价后换手率**（v6.3.0）；
- **异动·全市场相似历史（v6.3.0，激进/均衡档默认开启，可回测）**：个股近 20 个交易日
  「单日或 5 日累计涨跌超出自身历史 99.5 分位（底线 5%/10%）」即触发；系统在
  全市场历史异动中按 K线形态 + 事件后路径 + 量比 + 换手率 + RSI + 波动率匹配
  最相似的 50 例，统计它们在「事件后第 k 日」的未来 1/3/5 日表现；方向明确
  （次日上行≥55% 且均收正 / ≤45% 且均收负）时**覆盖原策略买卖点**，激进档
  相似样本次日封板率 ≥30% 附打板价提示；样本分歧则维持原策略。历史信号由
  因果信号生成器 `_sig_analog` 产出，**并入图表与单股回测统计，并作为
  「异动·全市场相似」算法进入消融候选池（12 算法，可被三档选型选中）**。
  示例：龙版传媒 2026-09-08 的 5 日 +59.8% 超历史分位触发，相似样本次日
  上行 56%、3日均 -0.9%，结论为分歧「观察」（不改判）。设置→预测参数可关。
  **全市场首跑结论（v6.3.0，7183 只有效消融）**：analog 入选稳健档 132 只
  （1.84%）、均衡档 91 只（1.27%）；候选描述性 IC 中位 IC1 +0.058 / IC5
  +0.041（53.5% 为正），优于 LGBM/L2、低于筹码峰；逐股导出 321 行覆盖
  156 只（入选偏差样本，收益不可与全市场中位直接比）；
- **基本面信息（v6.2.1，工具页）**：东财 F10 历史财报关键数据（近 12 期：营收/净利及同比、
  扣非、EPS、ROE、毛利率/净利率、负债率、每股经营现金流）表格展示 + 本地规则引擎分析
  （成长性/增收不增利/扣非背离/盈利质量/财务风险/综合结论），多源容灾+熔断，6 小时缓存；
- **数据层**：腾讯/新浪/东财/网易多源容灾 + 熔断自愈 + 本地 SQLite 缓存
  （全库 **1271 万根**日K，个股/指数深历史自 2016-11）；代码表含
  **换手率 / 动态PE / PB 快照**（v6.2.4，东财 clist 主源 + 腾讯行情备用通道）；
- **每日荐股**：三档组合目标持仓（稳健/均衡/激进）或 **18 策略共振综合**
  （v6.1.6，多策略命中数+均分排序）；**v6.2.0 起三档模式走「IC 确认层 + 综合分 Top10」**——
  先过滤「历史信号 IC 显著为正（120 日窗 IC>0 且 t≥2）且趋势指标在场」的股票再按档位
  评分取 Top10，资金按只均分（10 万 = 10 只 × 约 1 万，组合口径），确认不足宁缺毋滥；
  按设置中的行业/板块权限过滤，**默认剔除动态 PE≤0（亏损）股**
  （v6.2.4，ini `[picks] exclude_loss=0` 可关；估值快照来自代码表刷新，
  不参与历史回测），给出建议手数/金额/参考止损；
- **`test` 实验风险档（v6.4.0，手动选择）**：独立接入桌面 `sm701` 副本的
  LightGBM 概率模型；日K、股票名/行业/PE 等从副本 `stock_cache.db` 只读读取，
  历史分数读 `lgbm_output/valid_predictions.csv.gz`，已有预测之后的最新交易日
  用 `lgbm_output/lgbm_model.txt` 实时复算。`test` 采用 Top10、每日重排、无指数闸门，
  **不参与 AI 自动选档和默认三档回测**；默认路径为 `~/桌面/sm701 (副本)`，
  可用 `SM701_DIR` / `SM701_DB` / `SM701_MODEL` / `SM701_PRED` 覆盖。
  **注意**：sm701 是「次日开盘买→收盘卖」的日内口径，A 股 T+1 不可当日卖出，
  本仓库 T 收盘口径回测为负（详见「三档策略」末 `test` 小节），仅作研究观察；
- **AI 分析（可选）**：OpenAI 兼容接口，多轮问答、数据上下文缓存、AI 自动选档；
  **提示词随风险偏好动态生成**（v6.1.7 热修②）：保守=等确认/轻仓、稳健=兼顾、
  **激进（最高档）=板块轮动进攻、接受大波动、可直接给打板（涨停价）建议、禁用「等企稳/观望」搪塞**；
- **设置窗口分区导航 + 指标参数可调（v6.3.2）**：设置改 **PyCharm 式左侧分区**
  （外观 / 预测参数 / 指标参数 / 荐股 / AI 接口 / 关于），点选切页；
  **指标参数可在设置内调整并持久化**（ini `[inds]`）：MACD 快/慢/信号、
  KDJ N/M1/M2、RSI 短/长、BOLL 周期/倍数、**ADX 周期/平滑/趋势阈值**，
  带范围钳制与「恢复默认指标参数」；默认值与原硬编码一致，保存后重新分析生效；
  分析页标签（RSI/BOLL/ADX）随参数动态显示；作者信息移至「关于」页最下方；
- **信号胜率面板升级（v6.3.3）**：工具→信号胜率新增「**交易明细**」子页——
  全期/训练/验证三段逐笔列出「买入日@价 → 卖出日@价 / 收益 / 原因
  （信号卖出 / ATR止损 / 移动止盈 / 持仓中）」，可按段筛选、点列头排序，
  导出 txt/json 同步带逐笔明细；**「重选策略」改为「全部组合」窗口**——
  列出全部 算法×风险档 候选（优先流式读研究批量消融全量文件，秒开并标注数据日期），
  支持按 推荐档位 / 算法 / 风险档 / 综合评分 / 年化 / 胜率 / Calmar / 回撤 /
  交易数 等 14 种排列方式，选中任意组合即可应用，也可窗口内「本地重算」；

## 快速开始

### 环境

- Python 3.10+（开发环境 3.14）；
- GUI / 回测依赖 `numpy + scikit-learn + lightgbm`（`pip install -r requirements-client.txt`）；
  数据层与基础 CLI 纯标准库即可运行。

### GUI（推荐）

```bash
python stock_gui.py
```

首次使用：设置页填自己的 AI Key（可选）；「工具 → 数据工具」页可做
全库回填 / 数据清洗 / 复权失真体检，日志实时输出、可随时停止。

### CLI

```bash
python stock_predict.py 600519            # 单股分析
python stock_predict.py --tiers           # 三档当前目标持仓
python stock_predict.py --tiers --tier 激进 --universe main
python stock_predict.py --tiers --tier test   # sm701 实验档（需桌面 sm701 副本）
python stock_predict.py --tiers-backtest  # 组合回测摘要
python stock_predict.py --picks-backtest  # 荐股逐笔回测
```

### 一键全量回测（GUI 内置 / 桌面快捷方式）

**推荐在 GUI 内使用**：`工具 → 一键全量回测（全期/分段/逐股，后台）`——自动打开
「数据工具」页并启动，日志实时回流、可随时停止；也可在 `工具 → 数据工具` 页顶部
「一键全量回测」区块勾选「含逐年分段」后运行。流程：全期四口径 × 三档 → 样本外 `val` →
强势段 `bull`（可选逐年）→ 全市场逐股回测，各步结束自动刷新
`research/dashboard.html`，跑完自动打开；`工具 → 打开回测仪表盘（网站）`可随时查看。
桌面快捷方式「**一键回测**」等价（约 15~20 分钟，日志 `research/oneclick_backtest_*.log`）。
命令行入口：

```bash
bash run_backtest.sh            # 四步全量
bash run_backtest.sh --yearly   # 追加逐年分段
bash run_backtest.sh --dry-run  # 只打印将执行的命令
```

### 数据准备（可选，首次/换机）

```bash
python data_clean.py --db stock_cache.db           # 只扫描体检（不改库）
python data_clean.py --check-adj --sample 300      # 复权收益率保真体检
python backfill_full.py --workers 6 --throttle 0.45  # 全市场深历史回填（断点续传）
```

### 10 万元荐股组合回测（v6.2.0 新增，`backtests/backtest_picks10.py`）

120 日窗「近5日收益→未来5日收益」IC>0 且 t≥2 且样本≥60，且 T-1 日 MA20/60
多头趋势在场——IC 与指标综合考量、自然数阈值防过拟合），再按档位综合分取
**Top10**、每只约 1 万；三档均 10 日调仓；相位平均、含全部费用；

### 策略原理

**为什么是「动量 + 低波」而不是模型打分？** 2026-09-13 的审计（`reports/回测复核报告_20260913.md`）
证明逐股选型/ML 横截面打分在样本外归零（选择偏差 + 训练 IC 0.6 vs 测试 0.016）。
价格/量能类有效信息主要来自两类稳健风格：**趋势延续**与**低波动异象**，因此各档都只做
「横截面排序 + 趋势闸门」，不做参数寻优式拟合。

1. **合成排名（稳健）**：`score = rank(20日收益) + (1 − rank(20日波动))`，等权两项。
   动量项捕捉资金持续流入（趋势），低波项压低高波动/高换手个股的崩盘概率。
   注意：**动量权重不能进一步加大**——动量 Top 短名单方案回测全期 -51%
   （A 股 20 日动量 Top 全是妖股/ST，低波项是崩盘过滤器），60 日动量口径同样证伪。
   v6.3.1 收紧为 **Top10 + IC 确认层 + 换仓缓冲带10**：候选须同时过「历史信号
   IC 显著为正 + MA20/60 趋势在场」确认，且在位股未跌出 Top20 前不被替换——
   换手/交易数大幅下降（全A 9708→4180 笔，-57%），样本外（val/bull）显著增强，
   代价是全期最大回撤由 -8.6% 扩至 -19.5%（趋势确认层在 2023~2024 弱市更吃亏）。
2. **偏动量弹性（均衡，`blend_mom`）**：`0.7 × rank(20日收益) + 0.3 × (1 − rank(20日波动))`。
   v6.1.1 起主板均衡档（原激进档）用它替代 β 选股——提高动量权重增强进攻性，
   保留 0.3 低波作防守项；实测动量权重 0.6/0.7 稳健（+7.0%/+6.6%），0.9/1.0 崩坏（-10.5%/-28.2%）。
3. **β 选股（全A 均衡档）**：以 60 日对创业板指回归 β 排序，取最高 5 只。集中 5 只意味着高波动，
   所以必须配合慢闸门。**该口径仅在全A/创业板池成立**，主板池经诊断证伪（过拟合诊断见 `research/v61_report.md`）。
4. **趋势闸门（择时）**：`T-1 收盘 > MA(N)` 才允许持仓，否则调仓日清仓持现金。
   上证用 MA20，创业板用 MA60（慢，避免高波动指数被短期噪音反复打脸）；
   **激进档例外**：用「板块轮动闸门」——`0.6×行业广度 + 0.4×上证MA20 ≥ 0.35`，
   大盘权重从 100% 降到 40%，阀门打开更久（见下节）。
5. **调仓相位平均（tranche）**：单一调仓日的结果对「起始日运气」极其敏感，
   相位平均报告的是策略的期望表现而非某一次巧合。
6. **成交与费用**：T-1 收盘决策 → T 日收盘成交；滑点 0.1%/边、佣金万 2.5（最低 5 元）、
   印花税千 1（卖出）、过户费；100 股整手、涨停不买、跌停次日再卖、停牌顺延、
   退市/长停 20 日后按最后收盘价了结。**激进档例外（v6.1.7 起）**：解除「涨停不买」
   （`cfg.allow_limit_up=True`），涨停价视同可成交；历史回测中约 1.3%~1.9% 的
   买入发生在涨停价（ETF 池因涨跌幅小几乎为 0）。
7. **生产端口径差异**：GUI/CLI 的「当前目标持仓」额外剔除当前 ST/退市风险名称，
   并套用设置里的荐股权限（行业/板块）；历史回测无时点 ST 数据，故回测不含该过滤。
   激进档在持仓列表中用 `[涨停]` 标记信号日已封板的标的，并提示打板成交口径。

### 激进档 = 板块轮动策略（v6.2.3 定名，原高风险档 v6.1.9 开发）

**定位**：第三档「激进」＝ **板块轮动策略**（策略本体与 v6.1.9 逐字段相同，仅重定名），
风险偏好最高，**接受大幅波动**（回撤由使用者自行承受）。
与另两档「大盘择时 + 动量/低波」不同，它以**板块轮动**为主参考：

1. **选股 `rotate`**：`0.5 × rank(行业20日动量) + 0.5 × [0.7 × rank(个股20日动量)
   + 0.3 × (1 − rank(20日波动))]`——强势板块中的强势股优先；
   ETF/无行业标的的行业动量退化为自身 20 日动量（各自视作独立板块）；
2. **闸门 `rotation`**：`0.6 × 行业广度 + 0.4 × 上证MA20 ≥ 0.35` 才持仓。
   行业广度 = 20 日动量为正的行业占比。**大盘权重从旧口径的 100% 降到 40%**：
   大盘在均线上时阀门恒开，大盘走弱时约六成行业动量为正仍持仓——
   全期开闸 **1010/1636（62%）**，明显长于旧闸门（全A 创业板指 MA60=777、
   上证 MA20=857）；策略靠板块间来回切换，而不是空仓避险；
3. **Top5 / 每 10 日调仓**：高集中、高换手，各口径在其自己池内排序；
4. **允许打板**：解除「涨停不买」，信号日已封板的标的也按涨停价成交

5. **组合引擎不设止损**：只按「调仓 / 闸门 / 退市」进出；单股买卖点参数为
   保守/稳健/激进三组（v6.2.3 起原「高风险」参数组已删除，只作用于单股买卖点/
   消融/逐股回测，不影响组合引擎）。

### 三档引擎实现细则

**（1）特征构建**（`tier_build_features`，全部为面板级 numpy，因果：第 t 列只用 ≤t 的数据）

| 特征 | 定义 | 用途 |
|---|---|---|
| `ret20` | `C[:, t] / C[:, t-20] − 1` | 动量项 |
| `vol20` | 近 20 日日收益标准差（`cumsum` 滑窗，O(N)） | 低波项 |
| `amt20` | 近 20 日 `成交量(手)×收盘价` 均值 ÷100 → 成交额 | 流动性过滤（≥3000 万） |
| `barcount` | 累计有效 K 线数（`cumsum(isfinite(C))`） | 上市 ≥250 日过滤 |
| `beta60` / `beta60_sh` / `beta60_star` | 近 60 日对**创业板指 / 上证 / 科创50**的 OLS 斜率（协方差÷方差，滚动 60 窗口，需 ≥48 个共同有效日） | β 选股（`beta_star` 仅研究对照） |
| `sector_ret20`（`tier_sector_features`） | 所属行业成分股 `ret20` 的等权均值（行业来自 `stocks.industry`）；ETF/无行业退化为自身 `ret20` | 激进档板块轮动评分 |
| `sec_breadth`（同上） | `ret20 > 0` 的行业占比 | 激进档板块轮动闸门 |

**（2）评分族**（`tier_make_score`，横截面百分位 `rank01` ∈ [0,1]）

| 评分 | 公式 | 使用者 |
|---|---|---|
| `blend` | `0.5·rank(ret20) + 0.5·(1 − rank(vol20))` | 稳健（各口径） |
| `blend_mom` | `mw·rank(ret20) + (1−mw)·(1 − rank(vol20))` | 均衡（主板/ETF/全A含ETF，mw=0.7） |
| `rotate` | `secw·rank(sector_ret20) + (1−secw)·[mw·rank(ret20) + (1−mw)·(1 − rank(vol20))]`（secw=0.5、mw=0.7） | **激进（四口径）** |
| `mom` | `rank(ret20)`（纯动量） | 仅研究对照 |
| `beta` | `beta60`（对创业板指） | 均衡（全A） |
| `beta_sh` | `beta60_sh`（对上证） | 仅研究对照（已证伪） |
| `beta_star` | `beta60_star`（对科创50） | 仅研究对照（已证伪） |

排名在**口径自己的基数池**内做（`tier_rank_base`）：`all`/`main` = 个股池、
`etf` = ETF 池、`all_etf` = 个股+ETF，池外置 NaN 不参与排名。

**稳健档附加确认层（v6.3.1）**：
- `tier_ic_confirm`：120 日滚动窗「近5日收益（信号强度）→ 未来5日收益（结果）」
  Pearson IC，要求 T-1 日 `IC>0 且 t≥2 且样本≥60`，且 T-1 日 MA20/60 多头趋势
  在场（`c>ma20>ma60 且 ma20 上行`）；T 日决策只用 T-1 确认（无前视）；
- **换仓缓冲带 `hold_buffer=10`**：调仓时在位股排名在 `top+buffer`（Top20）内即保留，
  只有跌出缓冲带才被替换；该档 `ic_filter=True`（`TIER_CFG*`），
  `tier_eval`/`tier_picks_stats`/`tier_latest_picks` 均按档位配置自动生效。

**（3）闸门**：
- 趋势闸门（`tier_make_gate`）：`gate[t] = 收盘[t-1] > MA(N)[t-1]`，
  即**只用 T-1 及以前**判断 T 日能否持仓；关闭时调仓日清仓持现金；
- **板块轮动闸门**（`tier_make_rotation_gate`，激进档）：
  `gate[t] = 0.6 × sec_breadth[t-1] + 0.4 × (收盘[t-1] > MA20[t-1]) ≥ 0.35`，
  大盘权重 40%（旧口径为 100%），行业广度为主；关闭时同样调仓日清仓。

**（4）组合模拟**（`tier_sim_phase`，逐日循环）

- **调仓相位（tranche）**：资金分 `reb` 份、相位错开 `0..reb-1` 独立运行，各自以
  `top` 只等权目标持仓，最后把各相位净值按起点对齐后**平均**，报告相位年化区间；
- **成交**：T-1 收盘决策 → **T 日收盘成交**；滑点 0.1%/边；佣金万 2.5（最低 5 元）、
  印花税千 1（卖出）、过户费万 0.1；
- **整手**：按 100 股取整，买不起整手的标的跳过；
- **涨跌停**：涨跌停幅度按板块判定（创业板/科创板 20%，其余 10%），
  涨停不买、跌停不卖（次日再试）；**激进档解除涨停不买**
  （`cfg.allow_limit_up=True`，涨停价照常成交，回测中约 1.3%~1.9% 买在涨停价）；
- **停牌/退市**：停牌顺延；连续 20 日无 K 线按最后收盘价强制了结（`delist`）；
- **出局**：跌出目标 TopN（`target`）/ 闸门关闭（`gate`）/ 退市（`delist`）；
  稳健档启用 `hold_buffer=10` 后在位股跌出 Top20 才出局（`target`），
  且换入候选须先过 IC 确认层（确认不足留现金）；
- **新买入修正（v6.3.1）**：实际成交的买入会加入当期目标集合，
  避免「限价/整手跳过后买入的标的次日被旧目标误卖」。`

**（5）指标定义**（`_tier_metrics`，numpy 计算）

- 总收益 `eq[-1]/eq[0] − 1`；年化 `(eq[-1]/eq[0])^(1/年数) − 1`（年数按自然日/365.25，下限 0.05 年）；
- 最大回撤 `min(eq / cummax(eq) − 1)`；Sharpe `mean(日收益)/std(日收益) × √252`；
- 胜率 `(单笔 > 0).mean()`；PF `Σ盈利 / |Σ亏损|`；相位区间 = 各相位年化的 min/max。

### 消融算法细则（12 类信号，全部本地计算、AI 不参与）

| `vol_ratio` | 量比放量（v6.2.1 新增） | 近5/前15 量比首次上穿 1.2 且 ≥1.5、收阳 | 缩量 ≤0.5 或放量 ≥2.0 且收阴 | 复用 `vol_ratio_at`，因果序列 |
| `lgbm` | LGBM 预测（v6.2.1 新增） | `LGBMRegressor` 因果滚动训练（每 50 根用当日及以前 8 维特征重训）预测次日收益 > +0.5% | 预测 < −0.5% | 缺 lightgbm 库时该候选空集跳过（安装后正常参与） |

### 消融的事件回测口径与选优

**（1）事件回测**（`_bt_events`）

- 信号在 **T 日收盘**产生，**T+1 日收盘**成交；
- **ATR(14) 止损**：止损价 = 建仓价 − `atr_mult × ATR[t-1]`（ATR 用 `cumsum` 滑窗 O(N) 预计算）；
- **移动止盈**：最高价突破 `entry × trail_trigger` 后，止损上移到 `最高价 × trail_ratio`；
- 盘中最低价触及即成交（若开盘已跌破则按开盘价成交）；
- 逐日记录净值曲线 → 总收益/年化/回撤/胜率/PF；
- **牛熊分段收益**：上证 MA120 以上为牛、以下为熊，分段年化（numpy 掩码 + `log1p` 求和）。

**（2）三档风险参数**（`CFG.RISK_PARAMS`，消融中每类信号都跑这三组；v6.2.3 起三档，原「高风险」参数组已删除）

| 档 | `atr_mult` | `trail_trigger` | `trail_ratio` | `buy_th` | `cooldown` | 定位 |
|---|---|---|---|---|---|---|
| 保守 | 1.5 | 1.01 | 0.96 | 3 | 8 | 严进 + 紧出 |
| 稳健 | 1.5 | 1.02 | 0.94 | 3 | 8 | 严进 + 缓出（默认；v6.3.1 由 2/5 收紧） |
| 激进 | 2.5 | 1.05 | 0.90 | 1 | 3 | 宽进 + 宽出 |

> 三组参数均作用于**单股买卖点/消融/逐股回测**，组合引擎不设止损；
> 参数来源为 n=300/6000 回测网格（报告_买卖点收益回测.md）；
> 稳健档 v6.3.1 买入评分门槛 2→3、冷却 5→8（n=300 实测买点信号 -28%、中位年化
> 基本不变），与保守档入场同样严格，区别在止盈更宽（+2%/回落 6% vs +1%/回落 4%）。
> 原第四组「高风险」（ATR6.0 宽止损/冷却 2）随档位重定名于 v6.2.3 删除。

**（3）训练/验证切分与选优**

- 每个对象取近 **1000 根** K 线；**训练集 = 前 75%**（`split = n − max(200, n/4)`），
  **验证集 = 后 25%**（不参与多指标 rank 打分；近端一致性门槛会用到最近 250 根，
  n=1000 时即该段，属时点可观测数据、防风格切换）；
- 候选池 = 12 算法 × 3 档风险参数（含"样本不足"回退）；
- **多指标结合选优**（`pick_ablation_multi`）：把候选的 **Calmar、PF、胜率、年化**
  各自做横截面 `rank01` 后加权求最大 —— 稳健档权重 `0.45/0.25/0.20/0.10`（偏 Calmar+PF），
  激进档 `0.30/0.20/0.15/0.35`（偏年化+Calmar）；
  另设交易活跃度下限（≥8 笔，不足则放宽到 3 笔），避免选到"几乎不交易、回撤自然为 0"的假策略。
- **近端子窗一致性**（v6.1.5 热修②，`pick_ablation_consistent`）：最近 **250 根**也按同一
  权重 rank 取前 25%（下限 2 个），与全训练窗前 25%（下限 3 个）**取交集**，在交集中选
  全窗得分最高者；**交集为空 → 回退该档「多维评分」**；近窗可评估候选 <3 个时按全窗选。
  目的：防止长期横盘/旧 regime 选出的策略在风格切换后"沉默"（如 688012 于 2025-09 突破，
  RSI 策略近一年 0 交易——现已回退多维评分）。
- **GUI 单股消融**（工具→重选策略）与本节同口径：**12 算法 + 多维评分 × 3 风险参数 = 39 候选**
  （v6.1.4 补 L2；v6.2.1 加量比/LGBM；v6.2.3 起三档；v6.3.0 加异动·全市场相似；
  **v6.3.3 起按钮直接打开「全部组合」窗口列出全部候选**，可切换排列方式后任选其一应用，
  优先流式读研究批量消融全量文件、秒开，无覆盖才本地重算）；
  档位名是**选型目标**（保守档限定保守/稳健参数候选），候选后缀是它自身的风险参数；
  弹窗按**训练集** Calmar 给出推荐档；验证集仅展示且不参与指标 rank 打分
  （近端一致性门槛见上），高波动股（年化波动 >45%）推荐强制在 稳健/激进 中取较优。

### 性能与 numpy 加速（v6.1.3）

消融要在几分钟内跑完「**约 7000 个对象 × 12 算法 × 3 档 × (训练+验证)**」，
约 **40 万次事件回测**，故做了如下加速（结果与纯 Python 实现**逐笔一致**，有等值测试）：

| 环节 | 加速手段 |
|---|---|
| ATR(14) | `cumsum` 滑窗一次算完（O(N)），替代双重循环 |
| 事件回测 | 每对象的 **OHLC 平行数组只抽一次**（12 算法 × 3 档复用），循环内不再做字典取值；`rp` 参数与信号映射提到循环外；净值曲线的累计峰值/回撤/胜率用 numpy 一次算完 |
| 牛熊分段 | 逐日收益、牛熊掩码、`log1p` 求和全部 numpy 掩码化 |
| 面板特征 | 动量/波动/均额/上市天数/β 全为面板级 numpy（`cumsum` 滑窗 + 广播） |
| 形态距离 | `_px_distances` 用 numpy 向量化欧氏距离（较纯 Python 快约 50 倍） |
| 并行 | `ProcessPoolExecutor` 多进程 + 进程初始化器**注入**已构建好的行业序列（板块轮动/L2），避免每个 worker 重复加载全A面板 |
| 缓存 | 指数 regime、板块动量序列、L2 行业序列按进程缓存（TTL 30 分钟） |

> **实测对比**（8 进程，6924 个对象逐个消融）：
> v6.1.2 = 9 算法 **251 秒**；**v6.1.3 = 10 算法（含新增 L2）+ numpy 加速 = 181 秒**，
> 单位算法约快 **35%**，结果与纯 Python 实现逐笔等值（等值测试覆盖 5 只不同风格标的）。
>
> **L2 在消融选型中的占比（6881 个有效对象）**：稳健档 **7.88%（542 个）**、
> 均衡档 **9.42%（648 个）** —— 高于筹码峰（4.59%/4.67%）与板块轮动（2.7%/3.37%），
> 说明"同行业/行业ETF 时序趋势"是有效的选型维度。

    腾讯 hfq 实测为分段仿射、日收益被逐股缩放，已弃用）；ETF/LOF 无有效因子时用

## 已知局限

1. 组合回测区间自 2022-09 起（约 4 年，受特征/训练段要求限制），库内个股/指数
   深历史自 2016-11（2400 根）；仍**不能覆盖完整牛熊**；
2. **激进档**：全A 口径仍为创业板高β Top5 集中持仓，年化波动大、单年可能大幅跑输
   （2024/2025 已发生）；主板口径 v6.1.1 已改为 `blend_mom` top20（回撤 -12% 量级，
   不再是集中持仓），但**动量权重 0.9 以上会崩坏**，参数不可外推；
3. **科创50 是很强的基准**（全期年化 +12.8%、样本外 +21.5%、强势段 +35.4%）：
   激进档对科创50 的超额在多数区间为负，对创业板指/上证为正 —— 报告同时给出三基准，
   请勿只看单一基准判断策略优劣；
4. MA 闸门在单边强趋势中会滞后（2024-2025 跑输的直接原因之一）；
5. 整手约束下小资金（<10 万）无法完全复制 Top10/Top20 组合，实际需按资金量缩减股票数；
   **稳健档 v6.3.1 收紧后全期回撤由 -8.6% 扩至 -19.5%**（IC 确认层在 2023~2024
   弱市更吃亏、2025~2026 显著占优），请对照 `val`/`bull` 与逐年分段自行判断；
6. 未建模冲击成本/一字板，停牌与退市按最后收盘价了结，可能高估极端情形下的可回收价值；
7. 参数选型虽在训练段完成，但样本短、探索次数多，**仍存在选择偏差**
   （主板激进档的动量权重/参数是在全期扫描后选定，诚实说明与过拟合诊断见
   `reports/回测复核报告_20260913.md` 与 `research/v61_report.md`），
   请以样本外、逐年表与相位区间为准；
8. 荐股权限过滤在**历史回测中未启用**（无时点行业/ST 数据），实盘口径会略少于回测样本；
9. AI 分析输出为模型生成文本，**不构成任何投资建议**，其选档仅在三档之间选择，不参与选股与消融；
10. **ETF 数据长度不均**：1785 只有 K 线（884 只 ≥1000 根、其中 254 只 ≥2000 根，
    合计 181.4 万根），仍有部分上市较晚/规模较小的基金K线较短，
    故 ETF 口径组合在 2022~2023 年的样本偏薄，逐年口径不如个股口径可靠；
    货币/现金类 ETF 已剔除（近零波动会霸占低波因子），债券 ETF 仍保留 —— 它们在低波项上
    天然占优，**`all_etf`/`etf` 的稳健档会明显偏向低波资产**，这是特性也是局限；
11. ETF 无 ST/退市语义，`pick_allowed` 把它们归入独立 `ETF` 板块；若在设置里只勾选了
    主板/创业板/科创板而未勾 ETF，ETF 口径荐股会被权限过滤为空；
12. **异动·全市场相似（v6.3.0）**：异动分位阈值与相似度权重是按可解释性
    设定的先验（非样本外寻优）；全市场消融/三档选型已重跑（7183 只有效），
    但 analog 候选的**验证段年化中位为负、IC 为正**（描述性指标），
    「入选样本的中位收益」属选择偏差、不可当策略期望；样本分歧时系统会明确
    输出「观察」而不再给方向。目标股触发用精确逐日因果分位，全市场候选事件
    按各股分块因果分位提取（每 20 日重算，均为无前视）；换手率特征用当前
    总股本（`et_shares`）近似历史换手，送转/增发会带来偏差；首次触发需构建
    全市场事件表（约 24s，进程内缓存，后续瞬时）。
